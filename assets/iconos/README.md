# Icono del repositorio

Un único SVG, `perfil.svg`, usado en la cabecera del README y como icono de la carpeta del repositorio.

- Glifo: marca de `GitHub`.
- Formato: 64×64, `rx=16`, fondo navy con degradado (`#07131e` → `#0e2a47`) y glifo blanco relleno (`#f8fafc`).

## Origen y licencia

La marca procede de [Simple Icons](https://simpleicons.org/) (CC0). GitHub es una marca de GitHub, Inc.; se usa sin modificar y solo para identificar la plataforma.
